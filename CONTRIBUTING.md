# Contribution Guidelines

Thank you for helping to improve this list. Please read these rules before you open a pull request.

## What we list

- A working product or a maintained open-source project.
- Something the public can use or read. No private betas, waitlists or invite-only tools.
- A resource that is about AI video clipping: tools, open-source building blocks, guides, datasets or clipping work.

We list competitors of ClipX on the same terms as any other entry.

## What we do not list

- Fake reviews, inflated claims or invented numbers.
- Affiliate links, referral links or links with tracking parameters.
- Archived or abandoned projects, and links that do not load.

## How to add an entry

- Use this format: `- [Name](https://example.com) - Description.`
- Write one neutral line. Say what the tool does. No hype, no superlatives, no prices.
- Start the description with a capital letter and end it with a period.
- Use the canonical `https` link to the product or repository.
- Keep entries in alphabetical order inside each section.
- Add one entry per pull request when you can.
- Check that your link is not already in the list.

## Affiliation

If you work for, own or are paid by the product you add, say so in the pull request description. Affiliated entries are welcome when they follow the same rules.

## Removal and updates

Open an issue or a pull request if an entry is out of date, broken or wrong.

## Contact

For questions that do not fit an issue, write to admin@clipx.io.
